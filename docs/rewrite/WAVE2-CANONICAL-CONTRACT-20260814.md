- 专业版、定制版不是删除，而是当前 `retired_legacy`：停止公开展示、新购、续费及普通管理员赠送；历史订单、退款、原始方案名和未到期权益继续兼容。

## 推广与优惠码合同

- 只有通过有效推荐链接注册的新客户，其首个已支付会员订单享受 95 折。
- 优惠码先计算，再计算推荐 95 折；每单只能使用一张优惠码。
- 优惠码有开始／到期时间，首单客户和老客户均可使用。
- 非推荐链接注册没有推荐 95 折；已经不是首个已支付会员订单也没有推荐 95 折。
- 推荐人只获得被推荐人首个有效订单最终实付金额的 10%；续费、升级佣金为 0。
- 推广人数奖金使用后台配置的累计目标奖金阶梯，跨级只发差额，避免重复发放。
- 后台可配置佣金上限、奖金阶梯、最低提现、单次上下限、频率限制和暂停状态。
- 退款必须冲回佣金／奖金；订单必须保存规则、优惠码、推荐归因和价格计算快照。
- 仪表盘区分推荐客户、优惠码客户、订单、收入、折扣成本、佣金成本和退款冲回。
- 当前停售方案不得通过优惠码或推荐流程绕过会员策略；未来恢复后按当时不可变会员策略版本判定。
