**导航细节**：
- 图标 + 文字纵向排列，行高 ~80px，选中项蓝紫渐变圆角背景 + 白字 + 柔和投影。
- 底部用户卡：头像、账户名、会员标签、设置入口。
- 全局搜索：代码/名称搜索，最近搜索 ≤6 条，结果进 `/research`。

**顶栏细节**：
- 第一行：标题 + 搜索框 + "今日 15:00 ET" 时间 + 通知铃铛（未读红点）+ 头像。
- 第二行：页面级页签，选中项蓝色底部指示线（仅需要多视图的页面显示）。

| 区域 | 功能模块 | 细节设计 |
|---|---|---|

| **右栏 29%** | 股票筛选器 | 条件筛选卡：市场、行动状态、研究覆盖、事件、波动、数据状态下拉框；重置/应用筛选渐变按钮 |

| | 候选行动入口 | 打开研究/建立预警/生成个人模拟预填（选中股票时） |

## 9. 执行规则

1. **先骨架后内容**：每页先实现本文档的布局区域（用占位卡），截图确认后再填充真实业务组件。
2. **禁止空壳（最高优先级）**：每个布局区域**必须**放入现有真实业务组件与真实数据，禁止只画卡片边框留空、禁止 "占位" / "placeholder" / "待接入" 文字冒充完成。现有真实数据/API/组件没有对应的区域宁可暂不显示，也不得用假数据或空壳填。
3. **细节不丢**：项目总结中的功能模块逐项映射进区域，禁止遗漏；定稿没有的区域按本文档合理布局。
4. **业务不动**：只重构布局与样式，数据/API/路由/权限逻辑保留；数据源过期问题另行处理。
5. **每页验收**：视觉模型对比定稿 + 功能完整性检查（每个区域有真实功能），两者都过才合入。
6. **优先顺序**：发现页 → 今日总览 → 牛熊审议（当前 3 样板）→ research/paper/portfolio → 其余页面。
