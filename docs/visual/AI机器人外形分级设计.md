# CicloTrade AI 机器人外形分级设计方案（会员等级 × 智能体形态）

> 生成时间：2026-08-16
> 设计原则：机器人外形 = 会员等级 + 智能体能力阶段（L0-L4），用户升级后 AI 助手视觉同步进化，
> 形成"成长感"。参考图风格：深色背景 + 蓝紫粉霓虹 + 发光节点 + 3D 悬浮底座。

## 0. 设计总纲

- **同一角色，四种形态**：不是四个不同角色，而是同一个 AI 助手（Ciclo）随等级进化，保持"脸/眼睛/核心"家族特征。
- **家族特征（所有形态共有）**：
  - 圆润头部 + 双菱形眼（发光）
  - 头顶/背后光环（等级越高越复杂）
  - 底部悬浮底座（等级越高越华丽）
  - 主色跟随会员等级，但都含蓝紫粉渐变基因
- **形态升级** = 外观细节增多 + 光效增强 + 元素丰富，用户能直观感到"我的 AI 变强了"。

## 1. 四款机器人设计

### 形态 1：基础形态（免费版 / L0-L1）—— "新芽"
- **外观**：极简圆形头部，无光环，两只小圆眼（蓝），细短天线。
- **底座**：单层细光环（蓝，半透明）。
- **配色**：主体 #3B82FF 蓝，辅色白。
- **元素**：无多余装饰，干净利落。
- **寓意**：刚起步的 AI 助手，功能基础（行情+基础研究）。
- **SVG 特征**：circle 头部 + 2 个 eye + 1 条底座弧线。

### 形态 2：进阶形态（标准会员 / L2）—— "卫士"
- **外观**：头部加渐变（蓝→紫），菱形双眼中带光点，两侧小耳翼。
- **光环**：单层完整光环（蓝紫渐变，发光 8px）。
- **底座**：双层悬浮环 + 3 个小能量点环绕。
- **配色**：主体 #3B82FF→#7657FF 渐变，辅色白/浅紫。
- **元素**：头部两侧翼片（各 2 段），胸前小核心灯。
- **寓意**：AI 已具备完整研究+模拟能力，可靠守卫。
- **SVG 特征**：头部渐变 + 翼片 path + 双层底座。

### 形态 3：专业形态（专业会员 / L3）—— "智者"
- **外观**：头部复杂几何（多面体感），菱形大眼（紫粉），三叉天线，两侧大翼。
- **光环**：双层光环（粉紫渐变，发光 12px）+ 顶部悬浮皇冠点。
- **底座**：三层悬浮环 + 6 个能量点 + 底部粒子拖尾。
- **配色**：主体 #8B5CFF→#FF4FA3 渐变，辅色金/白。
- **元素**：胸前能量核心（旋转光晕）、肩部浮点 ×2、背后光带。
- **寓意**：完整专业能力（期权研究+策略+多智能体审议）。
- **SVG 特征**：多面体头部 path + 双光环 + 核心 + 光带。

### 形态 4：至尊形态（定制/旗舰 / L4）—— "神谕"
- **外观**：头部镶金边多面体（蓝紫粉金四色渐变），光翼展开（3 对），顶部皇冠光环。
- **光环**：三重光环（全色系）+ 环绕行星点 + 动态粒子流。
- **底座**：五层悬浮环 + 全息投影环 + 能量漩涡。
- **配色**：主体四色渐变（#3B82FF→#7657FF→#FF4FA3→#FFD700），辅色金。
- **元素**：全身节点连线（MARKET/NEWS/SIGNAL/RISK 四节点环绕）、数据流光带。
- **寓意**：平台最高级能力（受控 API+自动化+全部功能）。
- **SVG 特征**：复杂 path + 多光环 + 环绕节点 + 粒子系统。

## 2. 与会员等级的映射

| 会员等级 | 机器人形态 | 用户感知 |
|---|---|---|
| 免费/基础 | 形态 1 新芽 | "AI 刚起步" |
| 标准 | 形态 2 卫士 | "AI 开始有用" |
| 专业 | 形态 3 智者 | "AI 很强" |
| 定制/旗舰 | 形态 4 神谕 | "AI 是顶级伙伴" |

## 3. 尺寸与使用场景

| 尺寸 | 像素 | 使用场景 |
|---|---|---|
| S | 36-48px | 导航/顶栏/头像 |
| M | 54-72px | 卡片/状态区 |
| L | 96-140px | AI 横幅主视觉 |
| XL | 160-220px | 账户成长路径/AI 工作台 |

## 4. 实现方式

- React 组件 `AgentAvatar`（替换现有 v2-ciclo-avatar）：
  - props: `tier: 'free'|'standard'|'pro'|'flagship'`、`size: 'sm'|'md'|'lg'|'xl'`、`state: 'online'|'busy'|'offline'`。
  - SVG 内联绘制，无外部图片资源，随主题变色（currentColor / CSS 变量）。
  - 动效：光环旋转（慢速 6s）、能量点呼吸、粒子飘动；prefers-reduced-motion 关闭。
- 数据来源：会员等级从 Workspace bootstrap 读（现有 membership.tier 字段），无需新接口。

## 5. 验收标准

1. 4 款形态视觉差异明显（用户一眼能看出等级）。
2. 家族特征一致（都是"同一个 AI"）。
3. 深色/浅色主题都好看。
4. 动效流畅不干扰（150-220ms 交互动效，6s+ 氛围动效）。
5. 无外部资源，纯 SVG + CSS。
