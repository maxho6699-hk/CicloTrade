## 0. 三步设计法（每个页面都按此三步做）

**第 1 步：参考图排版理解** —— 页面属于哪种模板（见《参考图排版模式规范》4 种模板）
**第 2 步：我们的功能排版规划** —— 项目总结里该页的功能模块，按模板分配到区域
**第 3 步：设计元素融入** —— 霓虹渐变 / 玻璃拟态 / 3D AI 视觉 / 发光节点 / 迷你图表 / 状态体系

## 1. 内容精细度总则（所有页面通用）

### 1.1 禁止"空壳占位"
- 每个布局区域必须有真实业务组件 + 真实数据。
- 禁止：只有标题的卡、"--"、"待接入"文字冒充完成、空图表。
- 数据暂缺时显示明确空态（图标 + 说明 + 下一步操作），不用占位符。

### 1.2 数据展示精细度（参考图标准）
- 列表行：图标/Logo + 名称 + 关键数值（大号高亮）+ 迷你趋势图 + 状态标签 + 更新时间。
- 每张数据卡：标题行（左标题右操作）→ 内容（图表/列表）→ 底部指标行（状态点 + 时间戳 + 来源）。
- 数字：tabular-nums 等宽；涨绿跌红；关键数字 28-32px 放大。
- 图表：迷你 sparkline / K 线图形化，不用文字代替。

### 1.3 功能融汇原则（用户最新要求）
把相关功能**合并到同一卡片/区域**，减少跳转、提升效率：
- 候选股票卡 = 价格 + 迷你K线 + 涨跌幅 + 研究状态 + 证据数 + 操作（研究/自选/预警）融汇在一行。
- 账户卡 = 资产 + 收益 + 回撤 + 持仓数 + 风险等级融汇一张。
- AI 入口 = 输入框 + 建议问题 + 状态 + 快捷动作（生成草稿/比较/预警）融汇。
- 时间线 = 事件 + 状态 + 证据引用 + 结果融汇节点。
- 状态条 = 数据健康 + 模型版本 + 行情延迟 + 通知状态融汇。

## 6. 设计元素融入（每页必备，参考图标准）

1. **霓虹渐变**：主按钮 `linear-gradient(90deg,#FF4FA3,#8B5CFF,#3B63FF)`；选中导航渐变高亮。
2. **玻璃拟态**：卡片 `rgba(12,18,34,0.72)` + `blur(16px)` + 1px `rgba(120,145,255,0.16)` 描边。
3. **视觉锚点**：AI 机器人/发光底座/能力节点（MARKET/NEWS/SIGNAL/RISK）+ SVG 发光连线。
4. **迷你图表**：sparkline/迷你K线图形化数据。
5. **状态体系**：绿=正常/涨、红=风险/跌、黄=警告、蓝=处理中；状态点 + 时间戳 + 来源。
6. **高密度**：卡片间距 8-12px；行高 36-44px；页面边距 16-24px。
7. **底部状态条**：数据健康 + 模型版本 + 行情延迟 + 通知融汇。
8. **深浅双主题同构**：只换 token，布局一致。

### 6.1 机器人按会员等级显示（产品负责人 2026-08-16 明确）
AI 机器人（CicloCore 视觉锚点）的**形态随会员等级变化**，等级来自 `workspace.data.membership.plan`：
- **免费版**：基础机器人——单色/低光效，核心徽章灰色，底座小，无粒子/光环/能量线。视觉传达"基础能力"。
- **标准版**：进阶机器人——蓝紫渐变核心，发光底座，基础粒子，1-2 条能量线。视觉传达"增强能力"。
- **高级版**：高级机器人——霓虹外轮廓，粒子+光环+能量线辐射，胸口徽章发光，环形置信度仪表。视觉传达"完整能力"。
- **专业版**：专业机器人——全特效：银白金属机身+发光关节+全息底座+能量线+粒子+光环+环形仪表+顶部状态条。视觉传达"专业能力"。
- **定制版**：同专业版（或专属定制皮肤）。
- 未登录/演示模式：显示免费版或"未解锁"灰色形态 + 锁定提示（引导升级）。
- 实现：`CicloCore` 组件增加 `tier` prop（从 `useWorkspace().data.membership.plan` 读取），按等级切换 CSS class / SVG 细节。所有页面机器人统一走此逻辑。
9. **中栏占满**：主内容栏纵向撑满视口高度（flex-grow / grid 1fr），候选表+时间轴不留底部空白。

## 6.5 响应式设计标准（手机/平板/桌面三端，每页必做）

### 断点
| 端 | 宽度 | 布局 |
|---|---|---|
| 桌面 | >1180px | 三栏完整（18/51/29 或 65/35）+ 侧边导航 216-240px |
| 窄桌面/平板 | 701-1180px | 右栏变抽屉（汉堡按钮唤起）或两列；侧边导航收起 |
| 手机 | ≤700px | 单列卡片流；候选表变卡片（表格转卡片网格）；底部导航；触控目标 ≥44px |

### 手机端规则
- 三栏 → 单列：左栏→中栏→右栏顺序堆叠，或中栏优先 + 左/右折叠为抽屉。
- 表格 → 卡片：候选表每行变独立卡片（已有 .v2-candidate-table 模式）。
- KPI 卡 4 → 2 列网格。
- 按钮/触控目标 ≥44px；字体不缩小到不可读（≥10px 辅助、≥12px 正文）。
- 底部留出导航空间（padding-bottom: calc(76px + safe-area)）。
- AI 横幅：文字压缩、机器人视觉缩小或隐藏次要节点，保留渐变氛围。

### 平板规则
- 侧边导航可收起为图标条或汉堡菜单。
- 右栏状态卡可变为底部/抽屉（inspector-toggle 已有模式）。
- 卡片间距维持 8-12px，不放大留白。

### 验收
- 截图三端（桌面 1920 / 平板 1024 / 手机 390）逐页验收，无横向滚动、无遮挡、无大面积空白。

## 7. 执行方式（样板先行）

1. **发现页**（进行中）：按本文档第 2 节完成第三轮重做。
2. **今日总览 + 牛熊审议**：发现页验收满意后依次做。
3. **用户验收**：每页完成 → 截图 + 视觉模型对比（排版/密度/内容/元素）→ 用户确认。
4. **批量铺开**：3 样板全过 → 按第 5 节批量实现剩余页面。
5. **交付**：全部完成后走"推 GitHub → 推服务器"部署流程。
