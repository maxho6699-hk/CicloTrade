## 第一部分：会员体系与定价（头脑风暴融合：混元+Z.ai+Agnes）

### 1.1 核心策略
1. **视觉平权**：所有会员界面完全一致（全部元素展开），制造"功能触手可及"感；等级差异只在功能权限——锁定功能显示"会员专属"锁定态，引导升级。
2. **AI 是定价锚点**：审议/问答/研究链分级是付费核心。
3. **免费版留人**：基础功能够用 + 模拟账户体验，卡点设计促使升级。

### 1.2 功能权限矩阵

**自动实盘交易（产品负责人 2026-08-16 确认，重大决策）**：
- **高级版**：正股自动实盘交易资格
- **专业版**：正股 + 期权自动交易资格
- **申请流程**：填写风险保证文件（平台不承担任何责任，只提供数据分析及自动交易功能）
- **券商接入**：多平台接入（不止富途 OpenD——客户不一定用富途），支持用户绑定自有券商账号
- **AI 红线更新**：AI 提供数据分析与自动交易功能（由用户授权的策略引擎执行），交易责任在用户；原"AI 禁止自动下单"红线改为"AI 不承担交易责任，自动交易需用户授权+风险保证"
- **风控**：单笔最大金额、每日最大亏损、仅限授权市场（美股优先）等硬限制

### 1.4 免费版留人策略

### 1.6 AI 问答接入（产品负责人确认）
- **接入现有免费模型**：Agnes / Z.ai GLM / 腾讯混元 + DeepSeek 备用（免费成本≈0）
- **范围锁定**：AI 只能回答当前选中股票的研究问题（K线/证据/风险/比较），不开放自由聊天
- **白名单主题**：解释/比较/草稿/复盘（禁止荐股、禁止交易指令）
- **限次**：免费 3 次/天 → 标准 30 次/天 → 高级 100 次/天 → 专业不限
- **回答基于真实数据**：带引用的结构化回答（结论/引用/证据/风险/下一步）

### 1.7 资讯（新闻）功能（产品负责人确认）
- ✅ 要做：对标富途资讯，但聚焦研究（事件→股票关联）
- 内容：美股/港股新闻源（免费源起步）+ 财报事件
- 位置：研究页/发现页的事件流 + 个股新闻卡
- 社区（牛牛圈）❌ 不做

### 1.8 券商接入（多平台）
- 不止富途 OpenD：支持多券商（富途/盈透/老虎/长桥等），用户绑定自有账号
- 页面：券商目录 + 连接状态 + 资格申请（先做"未开放/申请制"状态，真实接入后启用）
- 自动交易：高级版正股 / 专业版期权，申请需风险保证文件

### 1.9 官方验证账户（打卡战绩，产品负责人确认）
- **账号**：美股 1 个 + A股 1 个，各自独立
- **起步资金**：US$10,000（美股）、A股对应（RMB 10 万或等值）
- **更新机制**：**每一波自动交易完成后自动更新**（余额/收益/回撤/胜率）
- **展示位置**：首页数据展示区 + 组合复盘页 + 今日总览 KPI（待模型讨论后定）
- **展示指标**：总资产、收益率、最大回撤、胜率、持仓分布、交易波次记录

### 1.10 自动交易风控（产品负责人确认）
- **用户自行设置**风控参数（单笔金额上限、每日最大亏损阈值），系统给出风险阈值提醒
- 美股 + A股都支持自动交易
- **风险保证文件**：网页勾选同意即可（有记录留存，为重要文件）
- 平台不承担任何责任，只提供数据分析及自动交易功能

### 1.11 AI 问答语言与画图（产品负责人确认 + 头脑风暴）
- **语言跟随用户**：简体用户→大陆语气；繁体用户→港式用语
- **画图**：用图表库（ECharts/Recharts）结构化渲染（K线/热力图/占比图/牛熊对比），**不用 AI 图片生成**（金融图表需精确可交互，AI画图有幻觉风险）
- AI 负责逻辑（生成 JSON 数据），前端图表库负责展示

### 1.12 资讯新闻（产品负责人确认 + 头脑风暴）
- **来源**：Finnhub（美股/港股）+ 新浪财经/东方财富（A股）免费组合——够用（15-30分钟延迟，定位"资讯聚合辅助"非实时信号）
- **翻译**：AI 翻译成用户语言（繁/简），**必须标注"翻译仅供参考，以原文为准"**
- **差异化**：AI 对新闻做情绪分析（不是看新闻，是看 AI 解读）——富途没有的能力
- 社区（牛牛圈）❌ 不做

### 1.12b TG 推送服务（产品负责人补充确认）
- **功能**：Telegram 推送**正股建议**和**期权建议**（核心功能，不能忘）
- **内容**：AI 量化信号 → 正股买入/卖出建议、期权策略建议（带证据/风险/失效条件）
- **权限**：免费版站内通知；标准版+ TG 推送正股建议；高级版+ TG 推送正股+期权建议
- **实现**：与通知中心/事件偏好联动（用户可订阅推送类型），推送到用户绑定 TG
- **触发**：每波自动交易完成 / AI 信号触发 / 财报事件 → TG 推送
- **频率控制**：用户可设置推送频率（即时/每日汇总），避免骚扰

## 第三部分：全站功能完整性对照（项目总结逐项核对 2026-08-16 补充）

> 来源：重新精读《项目总结-20260816》后的补齐项。**Codex 实现任何页面时必须保留这些业务能力**（视觉重做不删功能）。

### 3.1 法律与政策中心（PLANNED 页面，需设计）
- 服务条款、隐私政策、金融风险披露、付款与不退款政策、版本化同意收据、政策更新与重新同意
- 注册/会员订单/个人模拟/AI 数据授权/券商授权分别绑定对应政策版本
- 前端勾选不能代替服务端同意收据；拒绝新政策不阻止安全退出/账单/数据权利

### 3.2 Mystic 娱乐页
- 娱乐内容与正式量化研究完全隔离，明确"娱乐性质，不可作为依据"
- 贴文流（2 篇/页）+ 日期筛选 + 点赞；不得进入研究/AI/推荐/报告/通知/订单

### 3.3 Feedback 反馈页
- 五类反馈分类 + 来源路径 + 最多 2000 字正文 + 联系偏好
- 幂等提交（防重复）+ 历史回执列表

### 3.4 Help 帮助中心
- 按业务分类：数据与行情/AI/个人模拟/官方验证/会员付款/推广/Telegram/券商/隐私安全
- 风险与账户域说明（研究/官方/模拟/实盘区别）+ 问题处理与支持入口

### 3.5 AI Workflow 任务日志页
- 任务身份与上下文 + WorkflowRail 节点列表（queued/running/succeeded/partial/failed/cancelled/blocked/timed_out）
- 输入/输出制品（哈希绑定）+ 取消/重试/恢复 + 审计保留
- 状态映射：leased/heartbeat→queued/running；timeout→timed_out；禁止显示内部思维链

### 3.6 全局 AI 助手（跨页面）
- 会话与历史（新建/恢复/归档）+ 页面上下文快照 + 指令输入 + 结构化回答（账户域/数据状态/结论/引用/证据/风险/下一步）
- 引用与 provenance + 公开执行轨迹 + 受控工具动作（read/read_sensitive/create_draft/save_preference；broker submit 永久拒绝）
- 个人模拟草稿交接（无报价/风险证明、不能自动提交）+ 可控记忆 + 流式与恢复
- **AI 白名单**：解释/比较/草稿/复盘；禁止：无来源概率/收益承诺/伪数据/自动提交/暴露内部信息

### 3.7 Account 页补充（AI 记忆/数据授权/L0-L4/暂停）
- **AI 可控记忆**：用户查看/编辑/删除 AI 保存的市场、周期、风险、展示偏好
- **数据授权与隐私**：授权范围、撤回、删除、审计收据
- **智能体能力阶段 L0-L4**：L0 Kernel / L1 Scout / L2 Analyst / L3 Orchestrator / L4 Guardian——显示解锁条件和当前缺口（不评价收益/预测）
- **个人与平台执行暂停**：用户暂停（密码+确认文字恢复）vs 平台全局暂停（用户无权解除）
- 用量/支持/相关入口

### 3.8 推广中心（推荐归因/佣金/提现）

## 第五部分：全站统一设计语言（四模型融会贯通版）

> 来源：全局头脑风暴（豆包 8 节完整方案 + GPT 3,838 字 + 混元 3,693 字 + Zai 4,403 字）+ 用户已确认规范。**这是 Codex 实现任何页面的视觉宪法**——元素/排版/功能/会员在所有页面形成一致高级感。
> 融合规则：取各模型**差异化最佳方案**，冲突时以用户已确认规范和产品红线为准。

### 5.1 统一视觉语言层（设计 Token）

**色板系统**
- 背景层级：最深基底 `#050914`、内容区 `#0B1020`、卡片内 `#0F1730`、三级卡片深度 `#10182B/#151F35/#1B2740`
- 主渐变：`linear-gradient(90deg,#FF4FA3,#8B5CFF,#3B63FF)`——仅用于主按钮/重点标签/核心数据高亮/AI/会员/关键进度
- 功能色（低饱和适配深色，豆包修正）：成功 `#2DD4BF`、警告 `#FBBF24`、错误 `#F87171`、信息 `#58A6FF`、中性 `#94A3B8`
- 文本层级：一级 `#F1F5F9`、二级 `#CBD5E1`、三级 `#94A3B8`、辅助 `#64748B`
- **红升绿跌（GPT 关键洞察，香港市场习惯）**：涨红 `#F87171`、跌绿 `#2DD4BF`、平 `#94A3B8`；允许用户切换；盈亏色不得与品牌粉色混用
- 发光色：`rgba(255,79,163,.6)` 弱光、`rgba(139,92,255,.6)` 中光、成功光 `rgba(45,212,191,.5)`

**玻璃拟态**
- 标准玻璃卡：`rgba(12,18,34,.72)` + `blur(16px)` + `1px rgba(120,145,255,.16)` + `box-shadow: 0 12px 40px rgba(0,0,0,.28)`
- 悬浮玻璃卡（弹窗/下拉）：`rgba(15,23,42,.8)` + `blur(20px)` + `1px rgba(139,92,255,.25)` + 外发光 `0 0 20px rgba(139,92,255,.15)`
- 层级：L0 页面基底 → L1 内容区块 → L2 卡内子模块 → L3 悬浮弹窗 → L4 决策层（升级/交易确认/风险警告，最高对比）

**字体体系**
- 中文：Noto Sans HK / 思源黑体港版（PingFang HK 备选）；英数：Inter；数字/价格/代码/时间：Roboto Mono/IBM Plex Mono（等宽）
- 字阶：11/12/14/16/20/28px（大标题→数据标签）+ 核心大数字 40px
- **数字必须 tabular-nums 等宽对齐**（GPT 洞察），小数点/正负号对齐
- 行高 1.4-1.5；文字对比度 ≥7:1（WCAG AA+）

**间距圆角**
- 间距：8px 基数（8/12/16/20/24/32/40/48）；卡内 16px、模块间 12px（高密度不拥挤）
- 圆角：大卡 12px、子卡 8px、按钮标签 6px、品牌/会员卡 16-24px

**动效规范**
- 通用过渡 200ms ease-out；面板滑入 300ms ease；数据刷新数值滚动 500ms
- 霓虹呼吸光仅用于主 CTA（周期 2s），普通数据卡**不得全时发光**；单画面最多一个强发光中心（GPT 洞察）
- 卡片错峰加载（间隔 50ms）；按钮悬停 scale 1.02-1.05 + 描边增强

### 5.2 统一信息架构层（上下文传递）

### 5.4 统一状态语言
- **数据状态**：新鲜=绿色点+"2分钟前"；正常=蓝色点+"15分钟前"；延迟=黄色点+"1小时前"；失效=灰色点+"数据异常"+区域灰化
- **任务状态**：排队=灰脉冲点；运行=主渐变呼吸光+能量格进度条；完成=绿点；失败=红点+重试
- **会员锁定（视觉平权两级）**：轻锁定=按钮灰化+小锁图标+hover"升级解锁"气泡；重锁定=卡片 30% 黑遮罩+中央锁形+"升级至XX会员解锁"
- **账户域**：未绑定灰引导态、已生效域标识色、已过期红续费态
- 状态枚举统一：realtime/delayed/historical/stale/missing/invalid/disconnected/catching-up/research_proxy

### 5.5 统一行动语言
- **CTA 体系**：主按钮=主渐变+霓虹发光+白字；次按钮=玻璃描边+白字；文字按钮=主渐变色文字；尺寸 40/32/24px
- **升级引导分层**：轻=小字标签跳会员页；中=玻璃弹窗+权益+升级按钮；强=大机器人+权益对比+主 CTA（会员页/核心空态）
- **空态**：迷你 3D 机器人（低透明度）+ 简洁文案 + 唯一引导按钮（分无数据/未开通/无权限）
- **错误分层**：轻=卡内提示+刷新；中=弹窗+重试；权限=引导升级/切换账户

### 5.7 3D 机器人语言（全站锚点）
- **等级形态**：基础版（简约流线，免费/标准）→ 专业版（算力模块+装甲，高级）→ 高级版（全机甲+霓虹光效，专业/定制）——整体造型统一，差异仅细节复杂度
- **跨页尺寸规则**：大尺寸=欢迎/登录/会员页主视觉（品牌符号）；中尺寸=空态/升级引导/加载（≤卡 1/2 高）；小尺寸=头像/状态标识/列表前缀（24-32px 仅轮廓）；**禁用场景：数据卡片内部、表格行内**（豆包洞察，防干扰数据阅读）
- **融入原则**：主色调匹配页面渐变；非主视觉透明度 80%；仅缓慢悬浮/呼吸灯（周期≥2s）；始终服务内容不抢注意力

### 5.8 高级感 10 手法（可执行，四模型融合）
1. **分层玻璃叠压**：卡片错落排布形成前后层级（模糊度+描边强度区分深度）
2. **霓虹边缘呼吸**：主按钮/重点标签低强度常亮呼吸光，hover 增强，避免刺眼
3. **微可视化嵌入**：所有核心数值旁配迷你K线/能量格/状态点（图形传递趋势）
4. **负空间精准控制**：卡内 16px、模块间 12px，高密度不拥挤，拒绝无效留白
5. **渐变文字限用**：仅页面大标题/核心数据用渐变文字，正文纯色
6. **状态语义统一**：全端状态点/标签/进度条同一颜色语义，跨页无歧义
7. **3D 低融处理**：非主视觉机器人降透明度做背景点缀
8. **统一曲率体系**：全端圆角/贝塞尔参数统一（K线弧度/卡片/按钮）
9. **错落加载动效**：卡片错峰出现（50ms 间隔）+ 数值平滑滚动
10. **密度分级适配**：核心工作台高密度、入口页中密度（保留战绩+数据流，不空旷）、设置页中密度
