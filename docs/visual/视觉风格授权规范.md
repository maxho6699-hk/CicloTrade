## 2. 配色系统（参考图统一提炼，必须严格执行）

### 2.1 深色底（默认主题）

| Token | 值 | 用途 |
|---|---|---|
| 页面底色 | `#020914` ~ `#030B18` | 最外层背景，近黑蓝，**禁止纯黑 #000** |
| 侧栏/分区底 | `#030A14` ~ `#07101D` | 左侧导航、分区背景 |
| 卡片表面 | `#07111E` ~ `#0C1424`（常用 `#0A1524`） | 卡片背景，比页面底略亮 |
| 卡片高亮 | `#101A2D` ~ `#131E31` | 选中卡、hover 卡 |
| 边框 | `rgba(99,123,168,0.18)` ~ `rgba(114,148,190,0.18)` 或 `#1A2435` | 1px 低对比蓝灰描边 |
| 主色（蓝） | `#3478F6` ~ `#4B68FF`（常用 `#397BFF` / `#386CFF`） | 主按钮、链接、选中、图表线 |
| 强调色（紫粉） | `#C52BEA` ~ `#F348A0`（常用 `#E83BCB` / `#F23B9B` / `#EC3F87`） | 渐变第二/三色、AI 光效 |
| 主渐变 | `linear-gradient(90deg, #2878F5 0%, #7A45F5 55%, #C52BEA 100%)` | 主按钮、选中导航项、CTA |
| 正/涨 | `#22C77A` ~ `#36D98B`（常用 `#20BD78`） | 收益、上涨、成功、在线点 |
| 负/跌 | `#F05B78` ~ `#EB4668` | 亏损、下跌、风险 |
| 警告 | `#D9A52B` ~ `#FFC857` | 警告、过期、降级 |
| 主文字 | `#F4F7FC` ~ `#F5F6FA` | 标题、关键数字 |
| 正文 | `#B7C0D2` ~ `#A8AFC0` | 常规文本 |
| 辅助文字 | `#68748B` ~ `#737D91` | 次要信息、说明 |
| 禁用/等待 | `#4B566B` | disabled、waiting |

### 2.2 配色纪律（参考图的一致规律）

- **近黑蓝分层**：页面/侧栏/卡片/高亮卡 = 4 层递增亮度，绝不使用纯黑。
- **高饱和霓虹只用于**：选中态、AI 光效、主按钮、状态点——面积占比克制（≤5%）。
- **渐变统一**：所有主按钮/选中项用同一蓝紫粉渐变，禁止各页面各自造色。
- **绿=正、红=负、黄=警告**，金融语义色全站一致。
- 卡片 1px 低对比描边 + 轻微内发光，**不做大面积外发光**（发光只给选中项和 AI 主视觉）。
- 圆角：卡片 12~18px，按钮 10~14px，胶囊状态 999px。

## 3. 布局骨架（参考图 + 定稿一致确认）

所有页面统一为：**左侧固定导航 + 顶部工具栏 + 主体多栏仪表盘**

### 3.1 左侧导航（参考图统一规格）

- 宽度：`216px`~`240px`（约视口 11~14%）。
- 顶部：品牌 Logo（圆形/圆环图标 + 品牌名），深色底 + 霓虹描边。
- 菜单项：线性图标（20px）+ 中文文字，行高 `68~80px`，左右内边距 20px。
- **选中项**：蓝紫渐变暗底 + 1px 蓝色描边 + 右侧紫色高光边 + 圆角 14px + 轻微外发光。
- 底部：用户账户卡（头像、名称、会员标签、设置）。

### 3.2 顶部工具栏

- 高度 `80~98px`，含：页面标题/副标题 + 生产状态点 + 全局搜索 + 通知铃铛（红点）+ 渐变用户头像。
- 第二行（需要时）：页签行，选中项蓝色底部指示线。

### 3.3 主体仪表盘

- 12 列 CSS Grid，列间距 `12~16px`，页面边距 `24px`。
- 典型三栏：`320px + minmax(560px, 1fr) + 360px`（或按页面功能映射规范的 18/51/29 等比例）。
- 卡片网格：等高、对齐、1px 细线分隔；关键指标卡横向排列。

## 4. 核心视觉元素（参考图提取，必须出现）

### 4.1 3D AI 智能体主视觉（最重要）

- **每个关键页面（AI 助手、牛熊审议、今日/发现可选）必须有 3D 机器人/AI 主视觉**。
- 位置：主内容区中央或主卡片右半区。
- 底座：蓝紫霓虹圆形发光基座 + 径向光晕 + 粒子光点。
- 风格：轻拟物/赛博风，参考图风格一致。

### 4.2 能力节点连接线

- AI 主视觉周围连接能力节点（MARKET / NEWS / FINANCE / RISK / SIGNAL 等）。
- 连接线：**电流状蓝色发光曲线**，节点带状态点（绿=在线、黄=等待、红=风险）。

### 4.3 卡片体系

- 策略 KPI 卡：大号数字 + 迷你折线图（Sparkline）+ 状态标签。
- 研报/股票卡：Logo + 名称 + 涨跌幅 + 迷你趋势 + 置信度/状态。
- 榜单卡：横向排名条 + 热度。
- 任务进度卡：分段进度条（4 段）+ 状态圆点。
- Worker Log 卡：等宽字体实时日志 + 时间戳 + 任务标签 + 百分比进度。

### 4.4 状态体系

- 绿点 = 在线/成功；红点 = 风险/未读；黄点 = 等待/警告。
- 状态徽章：胶囊形，描边 + 文字。
- 数据源健康度：指示灯 + 延迟显示（如"延迟 15 分钟"）。

### 4.5 数据可视化

- 折线图：蓝紫渐变线 + 半透明面积填充 + 节点圆点。
- 迷你图：Sparkline（收益、趋势、热度）。
- 关键数字：放大 + 等宽数字（tabular-nums）。
- 涨绿跌红，图表线与状态色一致。

### 4.6 输入与按钮

- 输入框/下拉框：深色底（`#0B1424` 系）+ 1px 蓝灰描边 + 8~10px 圆角。
- 主按钮：蓝紫粉渐变 `linear-gradient(90deg, #2878F5, #7A45F5, #C52BEA)`，高 38~48px，圆角 10~14px，白字。
- 次按钮：深色底 + 蓝灰描边。
- 图标按钮：44×44px 触控，线性图标。
