# CicloTrade 参考图排版模式规范（第四份执行指令 · 排版总纲）

> 本文档提炼自用户参考图（`C:\Users\maxho\Desktop\参考图\` 8 张 + 用户补充参考图）的**功能页面排版模式**。
> 用户核心诉求：**页面太空旷、太疏散 → 必须高密度、多元素、像参考图一样丰富**。
> 此规范定义所有页面的**排版骨架模板**，与《视觉风格授权规范》《布局规范文档》《页面功能布局映射规范》配套执行。
> 执行优先级：视觉风格授权 > 本排版模式 > 布局规范 > 功能映射 > 旧合同。

## 1. 参考图排版的核心规律（为什么他们"丰富不空旷"）

分析 8 张参考图 + 用户补充图，总结出 5 条排版规律：

### 规律 1：顶部永远是"信息密集条"而不是大片留白
- 顶栏下方必有：**4 张等宽 KPI 卡**（数字 + 迷你趋势图 + 状态标签）或**通栏任务横幅**（表单 + AI 视觉）。
- 用户进入页面第一眼看到的是数据，不是标题和空白。

### 规律 2：主体永远是"主区 + 侧栏"的双区/三区结构，且每区内部都是高密度卡片流
- 典型：`顶部 KPI 条 → 主体（左 65% 主内容 + 右 35% 状态栏）→ 底部实时日志`。
- 主内容区是**多张卡片纵向排列**（不是单张巨表），每张卡有标题、图表、数据行。
- 右侧栏是**2-3 张纵向状态卡**（AI 状态、数据健康、任务队列、账户快照）。

### 规律 3：卡片内部"装满"——标题 + 图表 + 指标行 + 操作，没有空卡
- 每张卡：标题行（左标题右操作）→ 内容区（图表/列表/表单）→ 底部指标行或按钮。
- 卡片间距 8-12px（紧凑），内边距 12-20px。
- **禁止**只有标题没有内容的空卡。

### 规律 4：必有 1-2 个"视觉锚点"（AI 主视觉 / 工作流节点 / 发光连接）
- 参考图里几乎每页都有：3D AI 机器人、能力节点（MARKET/NEWS/SIGNAL/RISK）、发光流程线。
- 视觉锚点让页面有"焦点"，不是均匀平淡的表格堆。

### 规律 5：状态无处不在
- 每张卡、每个列表、每个节点都有状态点（绿/红/黄/蓝）+ 时间戳 + 数据来源。
- 高密度但不混乱：靠 1px 低对比描边、亮度分层、等宽数字维持秩序。

## 3. 全站通用"丰富度"规则（解决太空旷）

1. **KPI 卡前置**：有数字的页面顶部放 2-4 张 KPI 卡（带迷你 sparkline），不放纯标题。
2. **密度参数**：卡片间距 8-12px；页面边距 16-24px；表格行高 36-44px；卡片内边距 12-20px。
3. **每页至少 1 个视觉锚点**：AI 机器人 / 工作流节点 / 发光流程线（按页面功能选）。
4. **禁止空卡**：每张卡必须有标题 + 内容（图表/列表/表单/指标行）。
5. **状态全覆盖**：数据卡带状态点 + 时间戳 + 来源标签。
6. **右侧状态栏**：有侧栏的页面，侧栏放 2-3 张纵向状态卡，不放空白。
7. **底部实时条**：能显示执行/任务的页面，底部放日志/进度条。
8. **迷你图表**：列表里的数据用 sparkline/迷你 K 线图形化，不只用文字。
9. **指标行**：卡片底部加指标行（入场/目标/止损/风险比/时间），参考图研报卡结构。
10. **亮暗分层**：标题近白、正文浅灰、辅助蓝灰、禁用低透明度；关键数字 tabular-nums 等宽。

## 5. 验收标准

1. **不空旷**：首屏信息密度达到参考图水平，无大块空白（KPI 卡、图表、状态卡填满）。
2. **每页有视觉锚点**：AI 视觉/工作流节点/发光元素至少 1 个。
3. **每卡有内容**：无只有标题的空卡。
4. **高密度但有序**：1px 描边 + 亮度分层 + 等宽数字维持可读性。
5. **状态全**：数据都有状态点/时间戳/来源。
6. 与定稿骨架不冲突时，优先按本模板排版；冲突时以本模板为准（用户最新诉求）。
