# 产品反馈追加-第三轮（2026-08-16/17 线上验收）

> 产品负责人线上体验 ciclotrade.com 后的反馈，**14 条全部重要，逐条必须落实**。
> 优先级：G12 精美组件全局贯彻 > 其余全部并行。

## 发现页
### G1. 候选股票研究矩阵-竖列完全显示不全
- 问题：发现页中间的候选股票研究矩阵，竖列内容被截断/显示不全
- 修复：矩阵列完整显示（高度/宽度自适应，无截断）

### G2. 研究覆盖统计-卡片空位太多
- 问题：研究覆盖统计卡片空位太多，卡片尺寸不合理
- 修复：调整卡片尺寸（更紧凑），填充密度

### G10. 今日行动矩阵-做得不好
- 问题：发现页"今日行动矩阵"模块简陋难看
- 修复：重新设计行动矩阵（卡片式/状态标签/优先级高亮/操作按钮清晰/高密度）

### G11. 右侧两个按钮横排 + 卡片收窄
- 问题：截图右侧两个按钮竖排，卡片太宽
- 修复：按钮横排（并排），卡片宽度收窄紧凑

### G13. 推荐卡界面丢失（0基础用户推荐）
- 问题：项目原本方案的推荐卡（面向 0 基础用户）不见了
- 修复：恢复推荐卡——新手推荐/热门推荐卡片，有推荐理由，位置在发现页或首页

## 导航/路由
### G3a. "行情与研究"按钮跳发现页（路由逻辑错误）
- 问题：点击"行情与研究"导航跳到发现页，路由错误
- 修复：点击进入行情列表/研究页，而非发现页

### G3b. 缺市场行情总览（对标富途牛牛）
- 问题：富途牛牛式市场页面（大量股票可看：热门推荐/行情列表/板块）不见了
- 修复：新增市场行情总览——热门股票推荐、美股/A股排行、涨跌幅榜、板块

### G8. 牛熊页面入口丢失
- 问题：牛熊 PK 页（deliberation）入口找不到
- 修复：恢复牛熊页入口（导航或更多功能），路由 /deliberation 保留

## 页面重排
### G4. 个人模拟交易-整页排版不合理
- 问题：整页排版不合理，"账户待办"模块左右太宽留空太多
- 修复：整页重排——卡片收窄、减少留白、内容紧凑

### G5. 组合与复盘-排版没改+缺精美元素
- 问题：排版和之前一样没改过；精美设计元素没有
- 修复：按设计语言彻底重排（玻璃卡/霓虹/高密度/机器人）

### G6. 更多功能-按钮重复入口
- 问题：更多功能里按钮有重复入口（点击跳到左侧栏原有界面）
- 修复：清理重复入口——去掉重复按钮或赋予独立功能

### G7. 更多功能-组合成综合页面
- 问题：更多功能各项分散，希望组合成综合页面（类似个人中心整合布局）
- 修复：像个人中心一样整合——卡片分组/分类目录，非独立按钮堆砌

## 全局
### G9. 顶部导航区字体丑无设计
- 问题：多个页面顶部导航区字体丑、完全没设计感
- 修复：导航区按设计语言重做（Noto Sans TC 黑体/字号层级/玻璃霓虹选中态/图标配文）

### G12. 精美组件根本没看到（全局严重，最高优先级）
- 问题：一开始说好的精美设计元素（玻璃拟态/霓虹渐变/粒子/3D机器人/发光描边/渐变卡片）在实际页面里根本看不到——设计语言未落地
- 修复：**全站贯彻设计语言**：
  - 玻璃拟态卡片（rgba(12,18,34,.72)+blur(16px)+描边 rgba(120,145,255,.16)+内高光+阴影）
  - 主渐变 linear-gradient(90deg,#FF4FA3,#8B5CFF,#3B63FF) 按钮/高亮/进度条
  - 粒子/能量线/光晕细节
  - 3D 机器人按会员等级（useCicloTier/CicloCore）
  - 卡片五区模板、迷你K线、状态标签、圆盘比例、新鲜度徽章
  - 深浅主题同构
  - 每页必须能看到至少 3 种以上精美元素
