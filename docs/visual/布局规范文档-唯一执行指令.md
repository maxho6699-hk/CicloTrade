## 0. 总体设计语言（所有页面通用）

### 0.1 布局骨架（最高优先级，禁止偏离）

- **左侧固定导航栏**：所有登录后页面必须有左侧竖导航（宽度 ≈ 视口 11.5%~14.5%），图标 + 文字纵向排列。
- **顶部工具条**：页面标题 / 全局搜索框 / 时间 / 通知铃铛（带未读红点）/ 用户头像。
- **主体多栏布局**：核心页面为三栏仪表盘（左栏列表 + 中栏主内容 + 右栏详情/证据），次要页面双栏。
- **底部横跨时间轴**：发现页/复盘页在中栏下方或全宽处有近期事件/审议记录时间轴。
- 禁止：顶部横向主导航、单栏纵向堆叠、无侧栏的裸页面。

## 4. 执行规则（gpt-5.6-sol 必须遵守）

1. **改布局不改业务**：只重构 JSX/CSS 骨架与样式，业务数据、API、路由、权限逻辑一律不动；数据源过期问题另行处理。
2. **先骨架后内容**：先搭页面骨架（导航/栏位/卡片占位），截图确认后再填业务组件，禁止边搭边填导致走样。
3. **深浅双主题同构**：两套 token 共用一套布局；实现为 CSS 变量切换（沿用 `theme.ts` / `data-theme` 机制）。
4. **工作区**：在独立 worktree 中开发，禁止直接改生产源码树；完成并经视觉验收后再合入。
5. **每页验收**：完成后提供可运行 URL 或本地 dev server，由 Hermes 截图 + 视觉模型对比定稿，骨架不一致必须返工。
6. **禁止**：顶部横向导航、单栏堆叠、窄图标栏替代文字导航、删减时间轴/证据面板等定稿关键元素。
