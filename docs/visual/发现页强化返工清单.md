## 必须修复的差距（按优先级）

### P1 首屏重构为三列驾驶舱
- 左列 ~20%：账户概览 KPI 卡 + 信号/自选
- 中列 ~55%：AI 核心视觉 + 候选列表
- 右列 ~25%：筛选 + 持仓/模型状态
- 压缩顶部栏纵向占用，减少列表行高和留白 20-30%

### P2 3D AI 机器人主视觉（最重要）
- 中间主卡加入 AI 核心形象（可用 emoji/图标组合 + CSS 渐变圆环营造，或用 lucide-react 图标放大 + 发光底座）

- 下方椭圆悬浮底座 + 蓝紫粉光环 + 柔和投影

### P3 能力节点 + 发光连接线
- 围绕 AI 核心放 MARKET / NEWS / SIGNAL / RISK 四个节点卡
- SVG 贝塞尔曲线连接，蓝色外发光

### P4 霓虹配色变量（统一）

- 电光蓝 `#3B82FF`、紫 `#7657FF`、玫红 `#FF4FA3`
