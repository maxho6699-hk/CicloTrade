# CicloTrade 卡片内元素精细化设计规范（最终版）

> 生成：2026-08-16。来源：用户桌面参考图 4 张逐图拆解 + Z.ai/混元模型建议 + 用户要求（精美/更多适用元素/高级感/不强行塞入）。
> 本规范定义【卡片内部每个元素】的视觉细节，Codex 实现任何卡片都必须遵循。
> 总原则：**克制的高级感**——元素丰富但不杂乱，每个元素有明确信息用途；发光/渐变/动效服务于数据层级，不喧宾夺主。

---

## 0. 卡片基础骨架（所有卡片统一）

```
┌────────────────────────────────┐
│ 标题行: [图标] 标题   [状态点] [操作] │  ← 左标题右操作
├────────────────────────────────┤
│ 内容区（图表/列表/数据）            │
├────────────────────────────────┤
│ 底部指标行: [状态点] 时间戳 · 来源 · 值 │  ← 状态+时间+来源
└────────────────────────────────┘
```
- 卡片：圆角 12-14px，1px 细描边 `rgba(120,145,255,0.16)`，玻璃拟态 `rgba(12,18,34,0.72)+blur(16px)`
- 标题行：左图标+标题（13-14px 半透明白），右状态点+操作按钮
- 底部指标行：10-11px 辅助文字，状态点+时间戳+来源，细分隔线上方
- 卡片间距 8-12px，内边距 14-16px

## 1. 迷你K线 / 迷你趋势图（sparkline）

**参考图实测元素**：多色迷你折线（蓝/粉/绿/紫）、淡色面积填充、当前点、涨跌色区分

**规范**：
- 线条：**贝塞尔曲线**（非折线），1.5-2px，`drop-shadow` 微发光
- 填充：SVG linearGradient，顶部透明度 0.35 → 底部 0（面积渐变）
- 颜色：涨 `#00F0FF`（青）或 `#22C55E`（绿）；跌 `#FF4FA3`（粉）或 `#EF4444`（红）
- 当前点：最后一个数据点加空心圆点（白描边+发光），hover 显示 Tooltip（数值+涨跌幅）
- 尺寸：宽 60-90px，高 24-28px
- 网格：极淡 `rgba(255,255,255,0.04)` 横线 2-3 条（可选）
- 动效：加载时线条从左到右绘制（stroke-dasharray 动画）；hover 变亮

## 2. 能量格进度条（紧急度/强度/置信度）

**设计**（参考图：分段进度条+渐变填充）：
- 布局：**5 格横排**（或 4×2 网格用于复杂指标）
- 格子：圆角方块 14-16px，`border-radius: 3px`，间距 4-5px
- 填充：激活格 `linear-gradient(135deg, #7000FF, #FF4FA3)`（蓝紫→粉）；未激活 `rgba(255,255,255,0.06)` + 1px 暗描边
- 数值：格子右侧/上方 11px 等宽数字 + 单位
- 语义色（按用途）：
  - 紧急度：低=青 `#00F0FF` → 高=红 `#FF0055`（渐变过渡）
  - 置信度：蓝紫系（品牌）
  - 风险：绿→黄→红（安全到危险）
- 动效：激活格**呼吸脉冲**（opacity 0.8-1.0，2s）；入场逐个点亮（stagger 0.1s）
- 适用：信号置信度、流动性强度、风险等级、系统负载、数据新鲜度

## 3. 状态标签（pill/badge）

**参考图实测**：胶囊形、彩色圆点、紫色/蓝色/绿色标签、发光描边

**规范**：
- 形状：胶囊（border-radius: 999px），高 20-22px
- 背景：半透明 `rgba(255,255,255,0.04)` + `backdrop-filter: blur(4px)`
- 边框：1px 渐变发光描边（对应状态色 40% 透明度）
- 结构：左 8px 微型图标 + 文字（10-11px）+ 右状态点（可选）
- 状态色系：
  - **在线/成功/确认**：绿 `#22C55E`，图标对勾，边框绿 40%
  - **进行中/处理中**：蓝紫 `#8B5CFF`，图标旋转环（CSS 动画）
  - **警告/延迟/等待**：金 `#FFD700`，图标时钟，边框金 40%
  - **风险/失败/过期**：红 `#FF0055`，图标火焰/叉，边框红 40%，**每 2s 边框闪烁一次**
  - **信息/中性**：青 `#00F0FF`，图标信息
  - **离线/未连接**：灰 `#64748B`，无发光
- 动效：风险标签闪烁；其他静态微光

## 4. 圆盘 / 环形数据比例（confidence ring / gauge）

**参考图实测**：半圆仪表盘、环形进度、黄色环形状态图标、中心大数字

**规范**：
- 圆环：SVG stroke，直径 48-72px，描边宽 6-8px
- 缺口：顶部留 10-20° 缺口（科技感），`stroke-linecap: round`
- 渐变描边：`linearGradient` 蓝紫→粉（品牌）；语义色时按状态（绿/黄/红）
- 刻度：环外 12-24 个微型刻度点（`rgba(255,255,255,0.15)`，激活段亮）
- 中心：大号数字（18-24px 等宽）+ 单位/标签（10px 灰）
- 动效：加载时环从 0 填充到目标值（stroke-dashoffset 动画 1.2s）；数值同步滚动
- 适用：置信度、完成度、风险评分、占比、资金利用率、健康度

---

## 5. 数字与数据展示（金融终端核心）

**参考图实测**：大号数值（12 / 1,286 / 98.6% / 6.8s / $132.18 / ¥100,000）、绿色涨/红色跌、等宽数字

**规范**：
- 字体：**tabular-nums 等宽**（数字对齐），主数据 20-32px 半粗
- 涨跌：涨 `#22C55E`（+号），跌 `#EF4444`（-号），涨跌 13px 辅助
- 大数格式化：千分位逗号、$ 或 ¥ 前缀、% 后缀
- 单位标注：10-11px 灰色（如 "USD"、"7日"、"bps"）
- **涨跌动画**：数值变化时颜色闪动（涨绿闪/跌红闪，0.3s）
- 时间戳：`MM-DD HH:mm` 或相对时间（"2 分钟前"），10-11px 灰
- 迷你辅助数据：主数据下方 11px 灰色对比值（如 "昨收 228.10"）

## 6. 用户没想到的高阶元素（参考图+专业终端，适用才用）

### 6.1 数据新鲜度指示（时间差标注）
- 位置：数据旁或底部指标行
- 样式：`● 2分钟前`（绿=新鲜）`● 15分钟前`（黄=延迟）`● 过期`（红）
- 动画：新鲜时点缓慢呼吸；过期时闪烁
- 用途：行情、研究结果、证据、回测结果的时间语义（关键！体现数据真实性）

### 6.2 来源徽章（data source badge）
- 样式：微型徽章（10px 高），如 `YF`（Yahoo）、`AK`（AkShare）、`FD`（Finnhub）、`OPD`（OpenD）
- 颜色：按来源分配固定色（青/紫/蓝/绿）
- 位置：数据旁或证据卡片标题行
- 用途：数据源可追溯（产品核心卖点）

### 6.3 信号强度 / 方向指示
- 样式：1-5 格微型能量条（同第2节）或箭头（↑ 强多 / ↗ 偏多 / → 中性 / ↘ 偏空 / ↓ 强空）
- 颜色：多=青/绿，空=红/粉，中性=灰蓝
- 用途：AI 结论、牛熊倾向、趋势方向

### 6.4 迷你热力图（行情热度）
- 样式：5×N 网格，色块从深蓝（冷）→ 蓝紫（中）→ 粉红（热）渐变
- 用途：板块热度、事件热度、候选热度

### 6.5 横向排行条形图
- **参考图实测**：分类名+中央渐变条形（粉紫→蓝）+右对齐数值
- 样式：条宽 8-12px，渐变填充，末端圆角，基准线极淡
- 用途：涨跌榜、覆盖榜、热度榜

### 6.6 工作流节点 + 发光连线
- **参考图实测**：图标节点框 + 节点间蓝色发光连线 + 圆点 + 方向箭头
- 样式：节点 28-36px 圆角框（玻璃拟态），连线 1px 蓝紫渐变发光（CSS 动画流光）
- 用途：审议流程（观点→风险→草稿）、下单流程、回测流程

### 6.7 分类标签 + 高亮下划线（tab）
- **参考图实测**：横向分类标签，当前项高亮下划线
- 样式：文字 12px，当前项底部 2px 渐变下划线（蓝紫→粉）+ 文字高亮
- 用途：13/97 链切换、周期切换、视图切换

### 6.8 分段进度条（multi-segment）
- **参考图实测**：蓝紫色分段进度条 + 百分比文字
- 样式：4-6 段，段间 2px 间隔，渐变填充（蓝→紫→粉），末端数值
- 用途：研究覆盖进度、任务队列、资金分布

### 6.9 状态点（status dot）
- 样式：6-8px 圆形，中心亮边暗，`box-shadow: 0 0 6px 同色`（发光）
- 颜色：绿=正常、红=风险、黄=警告、蓝=处理、灰=离线、紫=AI
- 动画：正常=静态，处理=脉冲，风险=闪烁
- 用途：行首/标题旁的状态指示（参考图到处可见）

### 6.10 机器人角色插画（Alpha Pro 卡风格）
- **参考图实测**：紫蓝色机器人/宇航员角色插画 + 外框光晕 + 属性指标
- 用途：AI 相关卡片（AI 入口、审议中枢、会员等级）的视觉锚点
- 与会员等级联动（免费/标准/高级/专业递进）

### 6.11 2×2 数据子卡（嵌套）
- **参考图实测**：卡片内 2×2 子卡，每张含圆形图标+名称+大数值+涨跌+迷你趋势
- 样式：子卡间距 6-8px，细分隔线，hover 抬升
- 用途：多资产/多指标总览

### 6.12 环形/半圆仪表盘（gauge）
- **参考图实测**：半圆仪表 + 绿色数值 + 水平进度条
- 样式：半圆 180° 渐变描边，指针/填充弧，中心数值
- 用途：风险评分、利用率、健康度

## 7. 组合原则（避免"强行塞入"）

1. **每个卡片 1 个主元素 + 2-3 个辅助元素**（主=图表/大数，辅=状态/时间/来源）
2. 元素服务于**信息层级**：大数字→图表→标签→时间戳，视觉重量递减
3. 发光/动效只用于**状态变化或关键值**，静态内容保持克制
4. 免费版用户：隐藏高级元素（热力图/仪表盘/来源徽章），显示引导式元素
5. 专业版用户：全部元素展开，信息密度最大

## 8. 三端适配

- 桌面（>1180px）：完整元素
- 平板（701-1180px）：迷你K线保留，热力图/仪表盘折叠为点击展开
- 手机（≤700px）：能量格/圆盘保留（小尺寸），表格转卡片流，触控 ≥44px
