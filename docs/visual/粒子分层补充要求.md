# 牛熊审议素材集成补充要求（追加指令）

## 粒子分层细节（用户明确要求）

机器人的粒子效果**必须分层**，形成 3D 空间深度：

1. **后层粒子**（`z-index` 低于机器人）：在机器人背后——小的、暗的、模糊的粒子（opacity 0.2-0.35，blur 或小尺寸），分布在机器人轮廓后方，营造"空间纵深"。
2. **机器人本体**：中间层，清晰主体。
3. **前层粒子**（`z-index` 高于机器人）：在机器人前面——亮的、大的、清晰的粒子（opacity 0.6-0.9，带发光 drop-shadow），分布在机器人前方/四周，营造"浮在眼前"的层次。

## 实现方式建议

- 机器人容器用 `position: relative`，三个层各自 `position: absolute`：
  ```html
  <div class="deliberation-robot-stage">
    <div class="deliberation-particles-layer back"><i/><i/><i/></div>   <!-- 后层：模糊暗粒子 -->
    <img src="/assets/robot/robot-hero.png" class="deliberation-robot-img" />  <!-- 机器人本体 -->
    <div class="deliberation-particles-layer front"><i/><i/><i/></div>  <!-- 前层：亮发光粒子 -->
  </div>
  ```
- 粒子用 CSS 动画：浮动（translateY/translateX 随机位移）、闪烁（opacity 呼吸）、大小 3-8px 圆点，随机位置（用 nth-child 分散）。
- 前层粒子可加 `mix-blend-mode: screen` 让发光更亮；后层粒子加 `filter: blur(1px)` 更远感。
- 等级差异化：专业版前后层粒子全开；免费版全部隐藏或极少；标准/高级版逐步增加。

## 机器人细节

- 机器人图片 `robot-hero.png` 是深色背景素材——用 `mix-blend-mode: screen` 或圆形遮罩容器融合进页面背景，避免生硬方块边缘。
- 机器人底部加全息底座光晕（radial-gradient 椭圆），与素材的全息平台呼应。
- 周围保留能量线/能力节点装饰（MARKET/NEWS/SIGNAL/RISK 发光节点），连接线从机器人向四周辐射。
