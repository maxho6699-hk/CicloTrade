# CicloTrade 全站排版与内容规划（最终版）

> 生成：2026-08-16。输入：项目总结功能清单 + 混元/Z.ai 模型建议 + 用户三类用户群体 + 用户风格要求。
> 本规划 = 每个页面的【栏位结构 + 卡片内容 + 重叠检查 + 用户分层】，是 Codex 批量铺开的执行依据。

---

## 0. 三类用户群体（排版分层的核心）

| 用户类型 | 特征 | 信息密度 | 关键诉求 |
|---|---|---|---|
| **0基础用户** | 新手，看不懂专业数据 | 低密度、引导式 | 快速知道"今天看什么、为什么、风险" |
| **一般用户** | 有经验，会看K线/证据 | 中密度 | 完整K线、事件、证据、研究历史 |
| **专业用户** | 高阶/专业，要全量数据 | 高密度、全功能 | 完整证据链、模型版本、回测、审计 |

**实现**：按会员等级（免费=0基础、标准/高级=一般、专业/定制=专业）控制信息密度：
- 免费版：隐藏高级卡片（回测/期权/专业图表），显示引导卡
- 标准/高级：显示完整功能，中等密度
- 专业版：全部展开 + 高级筛选 + 数据审计细节

## 3. 内容重叠总检查（跨页面去重）

| 重叠内容 | 处理 |
|---|---|
| 待办事项（今日页 vs 通知页） | 今日=今日行动，通知=全部历史+投递状态 |
| 研究库（发现页 vs 研究页） | 发现=候选发现，研究=深度研究+保存库 |
| 证据面板（研究页 vs 牛熊页） | 研究=个股证据，牛熊=四席聚合审议 |
| AI问答（研究页 vs AI工作台） | 研究=单股上下文问答，AI工作台=通用会话 |
| 账户风险（今日页 vs 账户页） | 今日=摘要+跳转，账户=完整设置 |
| 数据健康（今日页 vs 更多页） | 今日=五合一状态条，更多=详情 |
| 持仓（模拟页 vs 组合页） | 模拟=个人域持仓，组合=官方验证域持仓（域隔离） |
| 回测（实验室 vs 报告页） | 实验室=运行回测，报告=验证结果审计 |

## 4. 优化空间（已识别）

1. **今日页行动矩阵**可加"一键进入研究"（减少一步跳转）
2. **发现页候选行**操作按钮（研究/自选/预警）三合一
3. **研究页底部交接区**：研究完成→直接进入模拟草稿（预填股票）
4. **通知页**可聚合 Telegram 推送状态
5. **会员页**加"等级机器人对比展示"（引导升级）
6. **底部状态条全站统一**（数据健康+模型+延迟+通知）
